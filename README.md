# DarNishByDestiny — Wedding Invitation V2

Luxury digital wedding invitation for Darshan Gajjar & Nishtha Ahuja.

Date: 29 November 2026
Ceremony: 7:30 PM
Dinner: 7:00 PM
Venue: Raj Party Plot, Anand, Gujarat

## Features
- Opening envelope animation
- Cinematic hero
- Personalized guest greeting with ?guest=Name
- Our Story timeline
- Memory gallery with fullscreen lightbox
- Romantic quote
- Wedding details and Google Maps
- Wedding itinerary
- Live countdown
- Hindi and Gujarati sections
- Google Calendar button
- Guest wishes demo
- Final cinematic section
- Responsive mobile design
- Music toggle

## Images
Put your actual image files in:
images/

The HTML expects:
- images/moon-hero.png
- images/couple-navy-day.jpg
- images/beach-wide.jpg

## Music
Put your licensed audio file here:
music/until-i-found-him.mp3

You can change the filename in index.html if needed.

## Personalized guest links
Examples:
?guest=Rahul
?guest=Rahul%20Shah

Example:
https://YOUR-SITE/?guest=Rahul%20Shah

## Important
The guest wishes section is currently a front-end demo. It does not permanently save messages. A backend/database can be connected later.
